# Setup app icons

These small icons identify the apps referenced in setup. They are bundled locally;
the wizard does not fetch icons or contact these services.

- Chrome: Google Chrome macOS app icon (`Contents/Resources/app.icns`).
- Safari: Safari macOS app icon (`Contents/Resources/AppIcon.icns`).
- Claude: Claude macOS app icon (`Contents/Resources/electron.icns`).
- Codex: Codex framework's Alerts helper app icon (`Contents/Resources/app.icns`).
- Activity Monitor: macOS Activity Monitor (`Contents/Resources/AppIcon.icns`).
- Cursor: `App Icons/PNG/APP_ICON_25D_DARK.png` from the official
  [Cursor brand assets](https://cursor.com/brand), retrieved September 22, 2026.

PNG thumbnails are 128 pixels, resized without changing aspect ratio. Names and
marks belong to their respective owners. Safari is shown for memory monitoring;
the setup copy identifies Chrome as the browser with tab cleanup support.
